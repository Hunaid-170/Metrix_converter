# Multi-Purpose Calculator System

This project is a multi-functional calculator developed as a semester project.

## Features
- Matrix Calculator
- Currency Converter
- Length Converter
- Area Calculator
- Mass Calculator
- Temperature Calculator
- Volume Calculator 

## Tech Used
- HTML
- CSS
- JAVA SCRIPT
